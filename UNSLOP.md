# 20 Ways to Unslop AI Designs
> *Production-Grade High-Craft Heuristics for Web & Mobile Interfaces*

---

### 1. Delete Filler Badges
Remove gratuitous pill badges (`✨ New`, `🚀 AI`). Use badges only for real status indicators (`Active`, `Present 0/2`, `Pending`).

### 2. Drop Redundant Labels
Stop writing `Email: john@doe.com` or `Role: Admin`. Position and context make meaning obvious.

### 3. Unitalicize Random Words
Avoid random italics for faux emphasis. Use font weight (`600`, `700`) and optical hierarchy instead.

### 4. Mono Only Where Needed
Reserve monospace for code snippets, hashes, and tabular figures. Use clean modern sans-serif everywhere else.

### 5. Use a Design System
Consolidate colors, radii, and spacing into centralized CSS custom properties (`--bg-app`, `--accent-green`, `--radius-md`).

### 6. Show the Actual Product
Ditch abstract 3D spheres and mesh blobs. Display actual working tables, cards, forms, and live data.

### 7. Enlarge the Main Feature
Create an obvious optical centerpiece rather than giving every component equal weight.

### 8. Group with Spacing
Use whitespace and proximity to group related items before reaching for heavy divider lines and nested borders.

### 9. Make Headlines Specific
Replace fluffy marketing jargon with functional, descriptive, task-oriented titles.

### 10. Emphasize the CTA
One primary call-to-action per viewport. Secondary actions should be subtle gray or outline buttons.

### 11. Add an Accent Colour
Pick one deliberate, punchy accent (e.g., emerald green `#00c06d`) on a crisp neutral foundation.

### 12. Keep Icons Consistent
Standardize on one icon library with matching stroke weights and bounding boxes across the entire app.

### 13. Remove Embellishments
Eliminate purple gradient text fills, neon border glows, and mesh grid backgrounds. High craft is restrained.

### 14. Nested Radii Formula
$$\text{Inner Radius} = \text{Outer Radius} - \text{Padding}$$
Keep nested corners concentric and mathematically harmonious.

### 15. Improve Text Contrast
Never use low-contrast washed-out gray on gray. Ensure body copy meets WCAG standards (`#111827` on `#ffffff`).

### 16. Wrap Headlines Properly
Prevent single-word orphan lines with `text-wrap: balance` or `text-wrap: pretty`.

### 17. Align by Eye, Not Just Pixels
Optically nudge play icons, chevrons, and badges so they appear centered to the human eye.

### 18. Use Tabular Numbers
Apply `font-variant-numeric: tabular-nums` to timers, clocks, stats, and prices to eliminate digit jitter.

### 19. Add Loading States
Provide polished skeleton loaders matching exact element shapes and button loading spinners.

### 20. Animate Useful Feedback
Keep animations snappy (`150ms - 200ms`) and functional: micro-clicks, subtle modal entries, and clear state changes.
